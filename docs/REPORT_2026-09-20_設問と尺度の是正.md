## 2. 🔴 予測が外れました — 閾値は変えていません（§4）

「逆転を入れると平均が中央に寄るので `>= 4` が立たなくなり、フォールバックに流れ込む」
と報告しましたが、**シミュレーションで否定されました。**

理由は単純で、**一貫して答える人は逆転項目があっても端まで届く**からです。
開放性が高い人は、正方向に5・逆転項目に1と答えるので、素点は 5.0 のままです。
中央に寄るのは**一貫していない人（＝回答スタイルで答えている人）だけ**で、
それはまさに狙いどおりです。

### 閾値の比較（潜在特性を1〜5で振った20,000件・full）

| 閾値 | 軸が1つも立たない人 | 一律回答で立つ軸数 `[全部1,2,3,4,5]` |
|---|---|---|
| **`>= 4` / `<= 2`（現行・変更なし）** | **0.8%** | **[0,0,0,0,0]** ✅ |
| `>= 3.75` / `<= 2.25` | 0.1% | [0,0,0,0,0] |
| `>= 3.6` / `<= 2.4` | 0.1% | [0,0,0,0,0] |
| `>= 3.5` / `<= 2.5` | 0.1% | **[5,0,0,0,5]** ❌ 一律回答が全軸で分類される |

現行値で一律回答は1軸も立たず、実在しうる人はほぼ全員どこかの軸が立ちます。
**引き直す必要がありませんでした。触っていません。**

## 3. 🔴 §5 の検査条件が、直した状態と両立しません

指示は「**4と5が同じ／1と2が同じ の状態を許さない**」でした。
しかし直した結果、**一律回答は5通りとも同じになります。**

```
全部1 → O2.50  全部2 → O2.75  全部3 → O3.00  全部4 → O3.25  全部5 → O3.50   （full）
全部1〜5 → すべて O3.00                                                    （light）
```

いずれも `>= 4` にも `<= 2` にも届かないので、**5通りとも「軸が立たない」に収束します。**

**これは欠陥ではなく、直った状態です。** 一律回答は情報を持たないので、
どの軸も立たないのが正しい。壊れていたときは値ごとに**別々の性格タイプ**が出ていて、
それは測定ではなく答え方を読んでいました。

そして、**値ごとに違うタイプを出させる閾値は、元の欠陥を作り直すことになります**
（上表の `>= 3.5` がそれです。一律回答が全軸で分類されます）。
指示の文面どおりに検査を書くと、**通すためには欠陥を戻すしかありません。**

そこで検査は**意図のほうに合わせて**書きました。判断を仰ぎます。

| 入れた検査 | 見ているもの |
|---|---|
| 一律回答は、どの値でも軸が1つも立たない | 回答スタイルを性格として読まないこと |
| 一律回答の素点は中央から±0.5に収まる | 同上（素点の側から） |
| **一貫して答えた人は素点が端（1.0 / 5.0）まで届く** | 逆転を入れて測定が鈍っていないこと |

3つ目を対にして置いています。1つ目だけだと「全員を中央に潰す」実装でも通ってしまうためです。

## 5. 🟡 別の吸い込みが残っています（今回の変更とは無関係）

24タイプへの分布（full・24,000件）は **24タイプすべてが使われます**が、
**マッチャ型が31.5%**を占めます。

```
マッチャ型 31.5% / ビブリ型 11.6% / レーダ型 10.4% / タクミ型 5.4% / 以下 3%未満
```

これは `determinePersonalityType` の**最後のフォールバック**です
（`utils.ts` の末尾 `return getPersonalityTypeById("contemplative-sage")`）。
判定木が `high` の組み合わせでしか分岐しないため、
E・O・A のどれも高くない人が全部ここに落ちます。

🔴 **今回の変更の前後で変わっていません**（旧31.9% → 新31.9%）。
逆転項目でも閾値でもなく、**判定木の構造**の問題です。

**直していません。** 24タイプ全部の境界を引き直すことになり、
第12便の範囲を超えるためです。別便で扱うかご判断ください。
