# light と full の不一致（分析のみ・実装していません）

作成: 2026-09-20 ／ 対象: 第14便§5で先送りした件

**結論から: 原因は「刻みの粗さ」ではありませんでした。** 依頼の4点に答えたうえで、
前提が変わる発見を2つ報告します。

🔴 **数字の読み方について先に。** 以下は「回答の揺れ幅」を仮定した
シミュレーションです。**実データはありません**（同じ人に2回受けてもらった記録が
無いため）。揺れ幅を変えると数字も動くので、**絶対値ではなく比較として読んでください。**
揺れ幅への依存は §5 に出してあります。

---

## 1. 🔴 刻みは原因ではありません

**ぶれずに答える人なら、light と full は 100% 一致します。**

| 揺れ幅 | full を2回受ける | light ↔ full |
|---|---|---|
| **0（ぶれない）** | **100.0%** | **100.0%** |
| 0.3 | 100.0% | 100.0% |
| 0.6 | 84.5% | 76.3% |
| 0.9 | 74.8% | 62.9% |
| 1.2 | 71.4% | 59.2% |

刻みが粗いことが原因なら、ぶれない人でも一致しないはずです。しません。

### 依頼4: 刻みより近い原型の組 → **0件**

| | 刻み | 5軸での最大ずれ | それより近い原型の組 |
|---|---|---|---|
| light（10問） | 0.500 | 0.56 | **0 / 276** |
| 15問 | 0.333 | 0.37 | 0 / 276 |
| 20問 | 0.250 | 0.28 | 0 / 276 |
| full（40問） | 0.125 | 0.14 | 0 / 276 |

原型間の最小距離は **0.91**、中央値は 3.02。**light の刻みで飛び越えられる距離に
並んでいる原型の組はありません。** 構造的に判別できない組は存在しません。

**本当の原因は、揺れの打ち消し方です。** full は8問の平均なので揺れが √8 に縮み、
light は2問なので √2 にしか縮みません。**問数は刻みのためではなく、
揺れを均すために効いています。**

---

## 2. 🔴 いちばん大きい発見: **full を2回受けても 74.8% しか一致しません**

同じ人が40問をもう一度受けると、**4人に1人が別のタイプになります。**

これが上限です。light の 62.9% は、100% と比べるべき数字ではなく、
**74.8% と比べるべき数字**でした。差は 12pt です。

**light を直しても 74.8% を超えられません。** 上限そのものが、この診断の
再現性の限界です。

---

## 3. 依頼1: 問数を増やしたときの一致率

| 版 | 1軸 | 逆転 | 合計 | full との一致率 | 上限までの残り |
|---|---|---|---|---|---|
| light（現行） | 2 | 1 | 10問 | **62.9%** | 11.9pt |
| — | 3 | 1 | 15問 | 68.0% | 6.8pt |
| — | 4 | 2 | 20問 | 70.1% | 4.7pt |
| full | 8 | 3 | 40問 | 74.8%（上限） | — |

- **10問 → 20問（2倍）で +7.2pt。** 上限までの差の6割を埋めます
- ただし**伸びは鈍ります**。15問で +5.1pt、そこから20問にして +2.1pt
- 逆転の割合は full（8問中3問）に近づけて選びました（2問→1、3問→1、4問→2）

---

## 4. 依頼3: 不一致はどこで起きているか → **小さいタイプに集中しています**

群による差はほとんどありません（不活性 41.2% ／ 連鎖 37.9% ／ 引火 35.4% ／ 沈降 33.5%）。
**偏っているのはタイプの大きさです。**

| タイプ | light で別タイプになる率 | 到達率（参考） |
|---|---|---|
| レーダ型 | **74.2%** | 1.8% |
| ウニコ型 | 64.4% | 1.3% |
| アトリ型 | 64.2% | 2.2% |
| ビブリ型 | 55.7% | 2.3% |
| … | | |
| マッチャ型 | 27.8% | 7.1% |
| フレア型 | 27.3% | 7.5% |
| ルナ型 | **23.4%** | 7.1% |

**到達率が小さいタイプほど、light で別タイプになります。** 受け持つ領域が狭いので、
揺れで簡単に外へ出ます。

🔴 **これは skip 中の「2.0%以上」の検査と同じ根です。** 痩せたタイプは、
痩せているだけでなく**不安定でもあります**。原型の配置で領域を広げれば
両方が同時に改善しますが、§1の通り、それは第13便で打ち切った作業です。

## 5. 依頼2: 所要時間 — 🔴 **現行の表記が食い違っています**

| 画面の表記 | 1問あたり |
|---|---|
| `10問 / 約2分` | **12.0秒** |
| `40問 / 約5分` | **7.5秒** |

**同じ画面（`/diagnosis/select`・LIFF版）に並んでいる2つの表記が、1.6倍ずれています。**
どちらを基準にするかで見積もりが変わります。

| | 12秒/問で | 7.5秒/問で |
|---|---|---|
| 15問 | 3分 | 1分52秒 |
| 20問 | 4分 | 2分30秒 |

**実測ではありません。** どちらの表記が実態に近いかは、
診断の所要時間を計測していないため分かりません。
`diagnosis_start` と `diagnosis_complete` の間隔を取れば出ますが、
Vercel Analytics の有効化待ちです（`BLOCKED` の項目7）。

**文面はこちらで書きません。** 表記を直す場合の判断材料として置きます。

## 6. まとめ

| # | 依頼 | 答え |
|---|---|---|
| 1 | 問数を変えたときの一致率 | 10問 62.9% → 15問 68.0% → 20問 70.1%（上限 74.8%） |
| 2 | 所要時間 | 現行の表記が1.6倍食い違っている。実測が無い |
| 3 | 不一致の偏り | 群ではなく**タイプの大きさ**。小さいタイプほど不安定 |
| 4 | 刻みの粗さ | **原因ではない。** 刻みより近い原型の組は0件 |

### 効きそうな順

1. **上限（74.8%）を上げる。** これが本体です。1問あたりの揺れを減らす——
   設問の文が曖昧だと揺れが増えます。**ここは文面の領域**です
2. **痩せたタイプの領域を広げる。** 不一致の集中と、skip中の検査が同時に解けます
3. **light の問数を増やす。** 20問で +7.2pt ですが、上限が74.8%なので天井は近い

**問数を増やすのは3番目です。** 刻みが原因でない以上、増やしても
「揺れを均す」効果しか無く、上限は動きません。
