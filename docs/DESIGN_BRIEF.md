## 1. サービスコンセプト（今回の刷新で確定した新コンセプト）

### Togel ＝ 言いにくいことを、告げる。

世の中にマッチングサービスと性格診断は無数にある。Togelはそのレッドオーシャンで戦わない。

**「相性のいい人」ではなく「絶対に合わない人」を告げる診断エンタメ**として全面刷新する。

- キーメッセージ例: 「**運命の人は教えない。地雷なら教える。**」
- 40問のビッグファイブ診断 → 24タイプ判定 → **ミスマッチ（合わないタイプ・ワースト5）が主役**。相性ベスト5は「おまけ」に降格
- 既存の名物コンテンツ「付き合ったら起こる地獄のシナリオ」「絶対にやってはいけないこと」を脇役から看板に昇格させる

### トーンの絶対ルール:「毒舌だが、愛がある」

- ボロクソ言うが、最後は必ず救う。突き放して終わらない
- 毒の対象は**タイプ**（「〇〇タイプとは最悪」）であって**個人**ではない。実在の人を傷つける見え方は絶対にNG
- 診断文体はすでにこのトーン（「主語がデカい」「細かい事務作業で死ぬ」等）。ビジュアルもこの温度に合わせる
- ホラー・グロには寄せない。「笑える危険物」「愛のある皮肉」の範囲で

### ターゲットと成長戦略

- 18歳以上の男女。SNSで自虐・毒舌系コンテンツを楽しむ層
- 収益は広告レコメンド枠のみ（課金なし）。**成長の生命線はシェア**: 「私と絶対合わないのは〇〇タイプw」がストーリーズ/Xに貼られること
- 流入の主力はLINE。診断→LINE友だち化→定期配信のループ

## 2. デザインへの示唆（コンセプトから導かれる要件）

1. **「危険物」のビジュアル言語が主役になる**。警告色・DANGER表現・封印/開封のメタファーなど。ただし前述のとおり「笑える危険物」。本気のホラーではない
2. **診断結果の開封体験を最重要の演出に**。「言いにくいことを告げられる」瞬間の緊張と笑い（例: 警告→開封→毒→救い、の流れ）
3. **ミスマッチカードが最強のシェア素材**。スクショ1枚で「誰と合わないか+なぜか」が伝わり、笑えること
4. 相性ベスト5・コーチング（=**地雷回避ガイド**: 合わないタイプとの付き合い方）は「毒のあとの救い」として明るめのトーンに切り替わってよい。毒と救いのコントラスト設計はデザイナーに委ねる
5. 3D回転メタリック会員証（既存の名物・`web/src/components/certificate/`）は維持・強化。「危険物取扱者カード」のような再解釈も歓迎
6. ロゴ資産: ネイビータイル + ピンクグラデの「T」モノグラム（`web/src/components/brand/togel-mark.tsx`）。現行カラー: プライマリ #E91E63 / ネイビー #0b1f3a。**継承するか刷新するかはコンセプトに照らして提案してほしい**（ロゴタイル自体は維持）

## 3. 刷新スコープ: 全ページ

**本依頼はサイトの全ページのビジュアル刷新です。** 優先度は「P1: 詳細カンプ必須 → P2: システム適用デザイン → P3: トークン適用のみで可」の3段階。

### P1: 詳細カンプ必須（サービスの顔になる画面）
| ページ | 役割 | コンセプト上の位置づけ |
|---|---|---|
| `/` トップLP | 「地雷なら教える」を宣言する看板 | 最重要。新コンセプトの第一印象を決める |
| `/diagnosis/select` → 性別選択 → `/diagnosis/[type]` | 診断フロー（ライト10問/スタンダード40問、1問1画面+進捗バー） | 「告げられる」までの緊張感の演出 |
| `/result/mismatch` | **ミスマッチランキング（新・主役画面）** | ワースト5+地獄のシナリオ+やってはいけないこと。シェアの発生源 |
| `/result` | 診断結果+相性ベスト5（おまけに降格） | 毒のあとの救い。ミスマッチとの動線設計含む |
| `/mypage` | マイページ | 3D会員証、診断履歴、お知らせ、友達紹介 |
| **地雷回避ガイド**（`/coaching` 系・新設） | 合わないタイプとの付き合い方・攻略法 | 毒の実用化。リテンションの柱 |

### P2: システム適用デザイン（レイアウト指示があれば十分）
| ページ | 備考 |

## 4. 技術的な制約・前提

1. **モバイルファースト必須**。流入の大半がLINE経由のスマホ。LINE内ブラウザ（WebView）でも崩れないこと
2. 実装は **Tailwind CSS + Next.js 16** で行う。トークン（色・角丸・影・余白・タイポスケール）は体系化して納品してほしい
3. フォント: 日本語は Noto Sans JP を使用中（変更提案は歓迎、ただしWebフォントとして配信可能なもの）
4. `/result` は情報量が非常に多い（性格解説、Big5スコア、5名分のカード、レコメンド枠）。ヒエラルキーの再設計（段階開示・タブ等）を提案してほしい
5. アクセシビリティ: ピンチズーム許可済み。コントラスト比は維持・改善方向で
6. 現行UIの確認は上記GitHubリポジトリの `web/src/app/` 配下（閲覧のみでOK）
