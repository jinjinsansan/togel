# Togel デザイン刷新ブリーフ（2026-08）

デザイナー（Claude デザイナー含む）への引き継ぎ資料。サイト全体のビジュアル刷新を依頼するにあたっての前提・スコープ・制約をまとめる。

## 1. サービス概要

**Togel（ツゲル）** — Big Five ベースの性格診断（24タイプ）で、相性の良い相手トップ5を演出付きで表示するエンタメ診断サービス。

- ターゲット: 18歳以上の男女。カジュアルに診断を楽しみたい層
- トーン: カジュアル・ポップだが安っぽくない。診断結果の文体はくだけている（「細かい事務作業で死ぬ」等）ので、ビジュアルもそのノリを受け止められる遊び心が必要
- 収益/成長戦略: 課金なし。診断→シェア→新規流入のバイラルループと、LINE友だち化が核。広告レコメンド枠（タイプ別提携サービス表示）が唯一の収益装置

## 2. 刷新スコープ：全ページ刷新

## 3. 現在のデザインシステム

- **カラー**: プライマリ `#E91E63`（ピンク）、`#ff5e93` グラデーション併用。背景 `#fdeef4`（淡ピンク）/ ダーク面 `#15181f` 系。ミスマッチページのみ赤/黒のダークトーン
- **フォント**: Noto Sans JP（`@fontsource/noto-sans-jp`）+ `font-heading` クラスの見出し
- **技術**: Tailwind CSS 3.4 + Radix UI（shadcn/ui系）+ lucide-react アイコン。`tailwind.config.ts` にトークンあり
- **ロゴ/ブランド**: `web/src/components/brand/togel-mark.tsx`、`web/public/togel-line-profile.png`、OGP `web/public/og.png`
- **既存プロトタイプ**: `redesign_extract/`（2026年6月のリデザイン時の Togel.dc.html 等）。前回刷新の到達点として参照可。ただし今回はこれに縛られなくてよい
- **名物コンポーネント**: `web/src/components/certificate/togel-certificate-card.tsx` — ドラッグ/自動回転する3Dメタリック会員証。ブランドの象徴として維持・強化したい
- **ヒーロー動画**: `web/public/hero-movie*.mp4` 複数バージョンあり

## 4. デザイン上の制約・要望

1. **モバイルファースト必須**。流入の大半がLINE経由のスマホ。LINE内ブラウザ（WebView）での表示も考慮
2. **診断結果ページの情報密度が課題**。現状714行分のコンテンツが縦一列。ヒエラルキーの再設計（タブ化・段階開示など）を提案してほしい
3. **シェアされることが最重要KPI**。結果画面・OGP・会員証カードは「スクショしたくなる/貼りたくなる」ことを設計基準にする
4. **アクセシビリティ**: ピンチズーム禁止はすでに撤廃済み（WCAG 1.4.4）。コントラスト比は維持・改善方向で
5. **年齢確認ゲート**（全画面モーダル）が初回表示される。この体験も刷新対象
6. 実装は Tailwind ベースで行うので、トークン（色・角丸・影・余白）を体系化した形で納品してほしい

## 5. 進め方・納品物

- コード側の整地とNext.js 16へのアップグレードは完了済み。デザイン実装はクリーンな main ブランチから行える
