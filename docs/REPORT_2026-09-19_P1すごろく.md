## 2. 指示への対応

| 指示 | 実装 |
|---|---|
| プログレスバー廃止・盤面が進捗 | 設問画面の上36dvhが盤面。バーは削除 |
| コマを中央固定・盤が動く | 盤を `translate3d` で動かし、コマは中央に固定 |
| 移動 0.35〜0.45s ease-out ＋着地 | `transform .4s cubic-bezier(.2,.8,.2,1)` ＋ コマの `scaleY 0.92→1`（80ms）＋ 盤の 2px の沈み（1回） |
| 連打で詰まらせない | **位置は現在地インデックスから導出**し、CSSが途中状態から次の目標へ補間する。キューを持たないので捨てる対象がなく、連打しても位置がずれない |
| 音を鳴らさない | 音は一切なし。`navigator.vibrate` も使っていない（iOSで無振動前提の設計） |
| `prefers-reduced-motion` | 変更を購読。ONなら移動も着地も封筒も即時。演出の途中でONになった場合は**残りを捨てずに畳む**（`reveal-sequence.tsx`） |
| full は4章×10マス | 章は**背景の細い区切り線と「第N章」の小さな表示のみ**。止まらない。中間マスより目立たせない |
| light は章分割なし | `buildBoard` は total===40 のときだけ章を作る |
| 中間マス（full 8回 / light 2回） | `MILESTONE_NUMBERS` に位置を持ち、盤上は黄色いリングで**手前から見えている**（予告と回収） |
| 中間マスの中身 | 区間内で最初に振り切れた回答（1 or 5）を1つ引き、`『{設問文}』——ここは「{ラベル}」でしたね。` を返すだけ。0件なら `ここまで {n} 問。どれも、はっきりとは振り切れていません。`。**解釈・軸名・スコア・残り問数は出さない**。但し書き「まだ途中です」は常時表示 |
| 「← 前の質問」は維持・後退は演出しない | 維持。移動の種類（forward / instant）を**操作を受けたページ側が決めて盤に渡す**。後退は transition も着地も無し |
| 途中再開 | 無音で現在地から開始。現在地の脇に「ここで止まっていました」を小さく添え、次の回答で消える。早送りなし・不在に触れない・ストリークなし |
| 俯瞰 | 盤の右上の「全体を見る」で同一画面内を縮小表示に切替 |
| コマの差し替え | `piece` プロパティでスロット化。既定は無地の丸 |
| 開封 | 回想（通ったマスが順に光り、振り切れた回答が1行ずつ・最大5行）→ その集積として封筒が現れる → 静かに開く → カードが1回反転。**カウントダウン・ドラムロール・シャッフル・光の強弱なし** |
| 共有導線 | 開封画面に共有は置かない。結果ページ（別画面）にのみ存在 |
| 現在地の正 | 回答の永続層（zustand + localStorage）。盤は座標を描くだけで状態を持たない |
| 再レンダリングで演出が飛ばない | 動きはCSS transition / animation で完結。`requestAnimationFrame` を state で回していない |
| dvh | 盤・各画面とも `dvh` |
| `will-change` | 動いている間だけ付ける |

### 軌跡（第6便の変更を反映）

- 各マスで線が通る点を回答でずらす。**符号は設問インデックスの偶奇で反転**
  （`trailOffsetX(index, value) = (index % 2 === 0 ? +1 : -1) × ((value - 3) / 2) × 16px`）
- 同じ回答「5」が設問ごとに左にも右にも出るため、一貫した「良い側」が**構造として存在しない**
- 太さ・濃さは回答によらず一定。差は形にだけ出る
- **シェア画像には載せていない**（9:16ラベルは第2便のまま。セッション内の表示に留めた）
