## 種別の意味

| 種別 | 何が書いてあるか |
|---|---|
| **報告（REPORT）** | 実装したことと、検証したこと・していないことの申告 |
| **照会（QUESTIONS）** | 仕様の穴。推測で埋めず、暫定の実装方針を添えて出したもの |
| **手順書（RUNBOOK）** | コンソール等を操作しながら手元で見るもの。確認できなかった項目を明記してある |
| **引継ぎ（HANDOFF）** | セッションの区切りでの状態。完了した時点の記録 |
| **依頼書 / 計画 / 要件** | 外部やプロジェクト初期に向けて書いたもの |

## ここに無いもの

- **テープ式心理学の知識ベース** … プロジェクトルートの `CLAUDE.md`。
  gitignore 済みのローカル専用。**コミットしないこと**
- **設計の決まりごと（トークン・命名・禁止事項）** … コードとテストの側にあります。
  `web/tailwind.config.ts`（デザイントークン）、`web/tests/`（不変条件の検査）、
  `web/tests/scope.ts`（刷新の対象外の宣言）
- **絵文字素材の出典と再配布条件** … `web/src/assets/emoji/NOTICE.md`
