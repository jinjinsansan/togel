## 4. 🔴 フォールバックの理由は「highが無いから」ではありません

これが今回いちばん重要な発見です。

フォールバックに落ちた6,466件のうち、**どの軸も high でない人は1,953件（30.2%）だけ**です。
**残り69.8%は、どこかの軸が high なのに行き先がありません。**

### 内訳

| 状態 | 件数 | 割合 |
|---|---|---|
| E中 / 高い軸なし | 1,953 | 30.2% |
| **E高 / 高いのは E だけ** | 1,607 | 24.9% |
| E中 / 高いのは N だけ | 911 | 14.1% |
| E中 / 高いのは C だけ | 857 | 13.3% |
| **E高 / 高いのは E と N** | 770 | 11.9% |
| E中 / 高いのは C と N | 368 | 5.7% |

### ここから読めること（3つ）

**(a) 入口が外向性でしか開いていません。**
分岐1〜6はすべて `high E` か `low E` を要求します。
**外向性が「中くらい」の人（全体の35.5%）には、そもそも入口がありません。**
その人たちの **47.9%** がフォールバックに落ちています。

**(b) 外向性が高くても、もう1軸が高くないと入れません。**
分岐1は `high O` を、3は `high C` を、4は `high A` を同時に要求します。
**「外向的だが、それ以外は突出していない人」（E高/high=E、E高/high=EN）は
合計36.8%を占めますが、行き先がありません。**

**(c) 神経症傾向を主とする入口がありません。**
N は常に「他の軸が高いことを前提とした枝分かれ」にしか出てきません。
**「Nだけが高い人」には入口が無く、全員フォールバックです。**

## 5. 絶対閾値を続ける限り、フォールバックは消えません

`>= 4` という**絶対値**で分岐する限り、「どの条件にも当てはまらない人」が必ず残ります。
割合を下げる調整はできますが、**概念としてのフォールバックは消せません。**
ご提案の相対比較（その人の中でどの軸が相対的に高いか）なら、
最も高い軸は必ず1つ以上あるので、行き先が無い人は原理的に生じません。

### ただし、相対比較でも「決まらない人」は残ります（実測）

| | 割合 |
|---|---|
| 1位がタイ（最も高い軸が1つに決まらない） | **10.0%** |
| 5位がタイ（最も低い軸が1つに決まらない） | 10.5% |
| どちらかがタイ | 19.6% |

素点は平均値なので刻みがあり、**full は 0.125 刻み、light は 0.5 刻み**です。
1位と2位の差は中央値で 0.50、下位10%では 0.12 しかありません。

🔴 **light は特に厳しいです。** 1軸2問なので素点が 0.5 刻みしか取れず、
5軸のうち複数が同じ値になる確率が高くなります。

**「フォールバックを消す」を達成するには、タイの解き方を設計に含める必要があります。**
ここを決めずに相対比較へ移すと、**フォールバックがタイ処理に化けるだけ**になります。
（順位の固定順で解く／2番目以降の軸まで見る／同点時の優先軸を決める、など）

## 6. 4群との関係（事実のみ）

ご指摘のとおり、4群の定義は2軸構造を持っています。

| 群 | 定義 |
|---|---|
| 引火群 | 外向 × 開放 |
| 沈降群 | 内向 × 思索 |
| 連鎖群 | 外向 × 協調 |
| 不活性群 | 内向 × 堅実 |

**4群はいずれも外向性を第1軸に使っています。** 現在の判定木が
外向性の高低でしか入口を開いていないのと同じ構造です。
相対比較に移す場合、**外向性を「高い/低い」ではなく「5軸の中での相対順位」で
扱えるか**が、群の定義を保てるかどうかの分かれ目になります。

**設計はしていません。** 地図として事実だけ置きます。
