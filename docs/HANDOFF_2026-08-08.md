## 2. 確定済みの意思決定（再議論しない）

| 決定 | 内容 |
|---|---|
| サービスコンセプト | **Togel＝言いにくいことを告げる。ミスマッチ（合わない相手）が主役**、相性ベスト5は「おまけ」。キーメッセージ「運命の人は教えない。地雷なら教える。」 |
| トーンの絶対ルール | 毒舌だが愛がある／毒の対象は**タイプ**であって個人ではない／毒のあとは必ず救う／ホラー・グロ禁止（赤 #ff5a5a はフォームエラー専用） |
| 収益・コスト | **課金なし・ランニングコストゼロ運用**。決済(One.lat)とMichelle AI(チャット)は封印継続（コードは温存、フラグOFF）。収益は広告レコメンド枠のみ |
| デザイン | 外部Claudeデザイナーの納品ZIP（`刷新.zip`、リポジトリにコミット済み）を全ページ実装。**ロゴは現行A案を維持**（ユーザー決裁）。プライマリ#FF2E74・ハザードイエロー#FFE03D・ダーク=毒/ライト=救いの2面構成 |
| 診断の呼称 | **「トゥゲル診断」（TOGEL INDEX）**。「ビッグファイブ」表記は全廃。5軸は独自名称: **引火点/構造強度/放熱量/緩衝性能/耐圧限界**（耐圧限界は表示時スコア反転） |
| マイページのカード | 「危険物取扱者カード」。旧カラー選択パネルは廃止（メタル固定） |
| ログイン | Googleのみ。LINEログインは認証未実装のためボタン非設置（実装するならSupabaseのLINEプロバイダ設定から） |

## 5. 運用メモ・ハマりどころ

- **環境変数**: `INVITE_SECRET` 未設定だと招待リンク／友達ミスマッチ診断が動かない（フェイルクローズ設計）。`INTERNAL_API_SECRET` は内部API用。Vercelには2026-06-24設定済みのはず
- **middleware→proxy**: Next 16で `src/proxy.ts` に改名済み（関数名も `proxy`）。ランタイムはnodejs
- **`next dev` の残留プロセス**: Windows環境でTaskStopしてもnodeが残りポート3000を握ることがある。`netstat -ano | grep :3000` → `taskkill //PID <pid> //F`
- **node_modules破損の前科**: 過去にfast-glob/next内部ファイル欠落で謎のビルド失敗。原因不明のエラーが出たらまず `rm -rf node_modules && npm ci`
- **web/AGENTS.md / CLAUDE.md**: `next dev` が自動生成する（Next 16のエージェント用ドキュメント参照）。コミットしてよい
- 管理者判定はメール2件のソース直書き（`proxy.ts` と `site-header.tsx`）— 既知の技術的負債
