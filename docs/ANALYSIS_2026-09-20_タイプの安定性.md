# タイプの安定性（分析のみ・実装していません）

作成: 2026-09-20 ／ 測定: `web/scripts/measure-stability.ts`

**安定性** = そのタイプと判定された人が、もう一度答えたとき同じタイプに留まる率。

🔴 **数字は「回答の揺れ幅」を仮定したシミュレーションで、実データはありません**
（同じ人に2回受けてもらった記録が無いため）。**絶対値ではなく比較として読んでください。**

**結論を先に: 配置を変えても、全体の安定性はほとんど動きません（74.9% → 最大76.0%）。
ただし最も不安定なタイプだけは、定義を壊せば 46.3% → 69.3% に上げられます。**

## 2. 依頼2: 到達率と安定性の関係 → 🔴 **相関はするが、引き上げても付いてきません**

相関係数は **0.86** で、到達率が高いタイプほど安定しています。
しかし**到達率を上げる介入をしても、安定性は上がりませんでした。**

| 配置 | 全体の安定性 | 最小 | 2%未満のタイプ |
|---|---|---|---|
| 現行（v6） | 74.9% | 46.3% | 5 |
| **到達率2%以上を満たす配置** | **74.6%** ↓ | **44.8%** ↓ | 0 |

**到達率の条件は満たしましたが、安定性は全体も最小も少し悪くなっています。**

理由は配置の作り方にあります。痩せたタイプの原型を人の多い側（重心）へ寄せると、
担当する人は増えますが、**増えた人は境界の近くにいます**。数は増えても、揺れで外へ出ます。

→ **「到達率を上げれば安定性も上がる」は成り立ちません。** 相関は観察であって、
その方向に押しても同じようには動きません。

## 3. 依頼3: 2%の検査を満たす配置にした場合の安定性 → **改善しません（-0.3pt）**

上表のとおりです。加えて**副作用があります。**

```
群の分離（O: 引火 > 連鎖）  維持
群の分離（A: 連鎖 > 引火）  🔴 破れた
```

**skip 中の検査を満たすためだけに配置を動かすと、群の骨格が壊れ、しかも安定性は改善しません。**
いまの skip を外す目的で配置を触るのは、割に合わないと考えます。

---

## 4. 依頼4: 安定性を最大化する配置と、定義を犠牲にする量

参考として、**データに最もよく合う配置**（k-means を20回。各原型を担当する人の
重心へ動かし続けたもの）を出しました。安定性の上限に近い配置です。

| | 現行（v6） | データに最もよく合う配置 |
|---|---|---|
| 全体の安定性 | 74.9% | **76.0%**（+1.1pt） |
| **最小の安定性** | 46.3% | **69.3%**（+23.0pt） |
| 到達率の幅 | 1.33〜7.58% | 3.02〜5.34% |

### 🔴 代償

```
v6からの移動           平均 1.76 ／ 最大 2.62（タクミ型）
群の分離（O）          🔴 破れた
群の分離（A）          🔴 破れた
元の位置より、他タイプの元の位置に近くなった原型   7 / 24
                       （ライオ型・ジェット型・ビブリ型・カンジ型・タイシ型・レーダ型 …）
```

**移動量1.76は、原型間の最小距離（0.91）のほぼ2倍です。** つまり隣のタイプを
またぐ距離を平均で動きます。実際 **24タイプ中7つが、自分の元の位置より
別のタイプの元の位置に近くなります。** その配置は、もはや同じタイプを指していません。

## 5. 判断材料のまとめ

| 何を買うか | 値段 |
|---|---|
| 全体の安定性 **+1.1pt** | 群の骨格が両軸とも壊れ、7タイプが別タイプの位置へ移る |
| 最も不安定なタイプ **+23pt**（46.3% → 69.3%） | 同上 |
| 到達率2%の検査を満たす | 安定性は **-0.3pt**、群の分離（A）が壊れる |

**全体の安定性は、配置では買えません。** どう並べ替えても 74.9% → 76.0% の範囲で、
上限が1ptしか離れていません。

🔴 **安定性を決めているのは配置ではなく、1問あたりの揺れです。**
揺れ幅を 0.9 → 0.6 にすると、配置を変えずに全体の一致率は 74.8% → 84.5% に上がります
（`ANALYSIS_2026-09-20_light版の一致率.md` §1）。**配置の10倍効きます。**

→ 設問の曖昧さを減らすほうが、桁で効きます。**そこは文面の領域**です。

---

## 6. こちらの見立て（判断は監督）

- **到達率2%の検査を満たすためだけに配置を動かすのは、勧めません。** 安定性は改善せず、
  群の骨格が壊れます。skip は skip のままにしておくほうが正直だと考えます
- **最も不安定なタイプ（レーダ型 46.3%）だけは、別の問題として残ります。**
  ただしこれを配置で直すには、7タイプが別タイプの位置へ移る規模の変更が要ります
- **安定性を本当に上げたいなら、設問の揺れを減らすのが唯一の桁の違う手です**
